# Laboratorios del proyecto integrador

**Empezá por:** `00_clase_teoria_y_practica_proyecto_rag.ipynb`. Contiene la
teoría del proyecto, tablas de requisitos, gráfico de arquitectura y práctica
inicial. Luego recorré los laboratorios:

1. **PIM_E01** — arquitectura y contrato público.
2. **PIM_E02** — documento, chunking, embeddings e indexación.
3. **PIM_E03** — retrieval, grounding y JSON.
4. **PIM_E04** — evaluación, benchmark y defensa.

Ejecutalos desde el directorio `proyecto_integrador/`. Las prácticas de arquitectura y validación funcionan sin API; la indexación y consulta reales requieren las dependencias del proyecto y `OPENAI_API_KEY`.
