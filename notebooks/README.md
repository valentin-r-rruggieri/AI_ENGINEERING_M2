# Notebooks didácticos AEM2

Cada notebook es una clase breve autocontenida con:

1. Problema real.
2. Referencia visual y conceptual.
3. Objetivos y teoría.
4. Diagrama o gráfico reproducible.
5. Predicción antes de ejecutar.
6. Práctica guiada y resultado esperado.
7. Errores frecuentes, desafío y cierre.

## Orden recomendado

- **L1:** embeddings, chunking y evaluación del retrieval.
- **L2:** índices vectoriales, búsqueda exacta/ANN y benchmarks.
- **L3:** ingesta, retrieval, grounding, contratos y evaluación RAG.
- **L4:** elección API/local, costo, privacidad y arquitectura híbrida.

Las fuentes visuales se citan dentro de cada notebook. Para validar la estructura:

python notebooks\validate_notebooks.py
