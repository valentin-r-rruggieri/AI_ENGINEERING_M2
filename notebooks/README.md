# Notebooks para estudiantes — AEM2

Cada lecture empieza con un notebook `00_clase_teoria_y_practica_*.ipynb`.
Es el punto de partida: explica la teoría con gráficos y tablas, desarrolla un
ejemplo desde cero y propone una práctica inicial. Después continuá con E01–E10
para aprender paso a paso y aplicar el concepto en ejercicios más pequeños.

## Orden recomendado

1. L1: `00_clase_teoria_y_practica_embeddings.ipynb`.
2. L2: `00_clase_teoria_y_practica_vector_stores.ipynb`.
3. L3: `00_clase_teoria_y_practica_rag.ipynb`.
4. L4: `00_clase_teoria_y_practica_ecosistema.ipynb`.
5. Proyecto: `proyecto_integrador/notebooks/00_clase_teoria_y_practica_proyecto_rag.ipynb`.
