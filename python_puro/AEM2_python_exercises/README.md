Ejecutá cada carpeta en orden numérico. Los scripts con `openai` requieren `OPENAI_API_KEY`; los demás son reproducibles sin red.

```powershell
.\.venv\Scripts\python.exe python_puro\AEM2_python_exercises\AEM2L1_embeddings_fragmentacion\e01_similitud_manual.py
```

Cada lecture incorpora `data/generate_data.py`, un README local y cinco scripts: concepto base, problema, solución robusta, evaluación y mini-integrador.

Los scripts están comentados como material de estudio: los comentarios explican la decisión o el concepto que se está aplicando (por ejemplo, normalización, Top-K, grounding o Recall@K), no repiten literalmente lo que ya dice Python.
